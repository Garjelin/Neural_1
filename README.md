# Neural_1 — Многослойный персептрон

Лабораторная работа №1 по дисциплине «Теория нейронных сетей».

**Вариант №5:** Многослойный персептрон (бинарные функции активации). Аппроксимация данных.

## Описание

Программа реализует многослойный персептрон (MLP) с архитектурой 1 → 5 → 1 для задачи бинарной классификации функции y = x².

### Особенности:
- Функция активации: единичный скачок (step function)
- Алгоритм обучения: правило Розенблатта
- Автоматическая генерация HTML-отчёта

## Сборка и запуск

### Требования
- CMake >= 3.15
- Компилятор C++ с поддержкой C++20 (GCC, Clang, MSVC)

### Инструкция

```bash
# 1. Перейти в папку проекта
cd Neural_1

# 2. Создать папку для сборки
mkdir build
cd build

# 3. Сгенерировать Makefile
cmake ..

# 4. Собрать проект
cmake --build .

# 5. Запустить программу
./Neural_1
```

### Результаты

После запуска программа:
1. Считывает данные из `train.dat`
2. Обучает многослойный персептрон
3. Выводит результаты в консоль
4. Создаёт файлы:
   - `output.txt` — текстовый отчёт с результатами
   - `index.html` — HTML-отчёт для сдачи лабораторной

## Структура проекта

```
Neural_1/
├── CMakeLists.txt          # Конфигурация сборки
├── README.md               # Этот файл
├── train.dat               # Обучающие данные (y = x²)
├── index.html              # HTML-отчёт (генерируется автоматически)
├── output.txt              # Текстовый отчёт (генерируется автоматически)
└── src/
    ├── main.cpp            # Основная программа
    ├── report_generator.h  # Заголовок генератора отчётов
    └── report_generator.cpp # Реализация генератора отчётов
```

## Архитектура сети

```
Вход (x) → [5 нейронов скрытого слоя] → [1 выходной нейрон] → Результат (0 или 1)
```

Скрытый слой формирует «разделяющие прямые», позволяющие классифицировать нелинейно разделимые данные.
